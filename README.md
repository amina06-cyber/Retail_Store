# Retail Store ETL Pipeline
I built an ETL pipeline using **PostgreSQL, DBeaver, and SQL**, working with retail data from raw CSV files and turning it into a structured database for analysis.

### What I Worked On
* Database and schema design
* CSV data ingestion
* Source, staging, and warehouse tables
* Data cleaning and transformation
* CTEs and window functions
* `LEAD()` and `LAG()`
* Business and analytical SQL queries
* Git and GitHub workflow

### Dataset
* Customers
* Products
* Orders
* Payments

### What I Learned
This project helped me understand how raw data moves through different stages before it can actually be used for analysis. I also got much more comfortable with PostgreSQL, advanced SQL, and Git.
